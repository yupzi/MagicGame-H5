# 魔法丘陵 Magic Hills

横版像素魔法探索冒险游戏原型。用 TypeScript + Canvas 写成，所有美术和音效都由代码实时生成，没有外部素材。

## 运行

- **最简单的方式**：双击 `start.bat`，浏览器会自动打开游戏
- 命令行：`npm install`（只需一次），然后 `npm run dev`，打开终端里显示的地址

| S / ↓ + 跳跃 | 从云朵平台上落下 |

## 魔法小屋

你住在丘陵起点的小屋里，每次开始游戏、在家附近倒下时，都是从小屋门口走出来。

- **进屋**：走到门口按 ↑。屋里是一个房间，左右走动，走到家具旁按 ↑：
  - **小床**：睡一觉，进入新的一天（墙上的日历会翻页），回满体力、自动存档，所有被砍倒的树和打碎的石头重新长出来
  - **书桌**：翻开魔法星盘
  - **编织台**：符文编织（台上漂浮着你手里魔法的魔法阵）
  - **门**：出门
  - 窗外能看到花园里的朋友；星盘（E）和编织（R）在任何地方都能打开
- **把朋友领回家**：用花之魔法交到的兔子和野猪会一直跟着你。带它们走回小屋旁边的花园，它们就会搬进来（最多 6 位）。走太远它们会跟丢，停在原地等你
- **花园**：兔子蹦蹦跳跳，野猪慢悠悠地散步、打盹；你走近时它们会冒出爱心
- **每日礼物**：每睡一觉，花园里的每位朋友都会留下礼物：兔子送软毛（有时还有苹果），野猪从地里拱出石头（有时是水晶）。礼物会一直等你来拿
- **兔毛**：野外的兔子被打倒不再掉落任何东西，毛皮要靠花园里的兔子朋友（野猪仍然会掉毛皮和肉）
- **朋友不会受伤**：你的魔法打到动物朋友，它们只会吓一跳
- **旅行灯笼**：花园门口的灯笼可以直接去最远点亮的灯笼；在其它点亮的灯笼旁按住 ↓，可以回家。身边跟着的朋友会一起走

## 符文编织

每个魔法都由两枚符文织成：**元素 + 形态**。

- **元素符文**（星 / 火 / 冰 / 雷 / 花）：在魔法星盘里用材料点亮。星是一开始就有的；花之符文挂在「丰收」后面
- **形态符文**（弹 / 环 / 柱 / 抛）：在世界里的古老石碑上拓印，走到石碑旁边就会自动开始。弹是一开始就有的
- 按 R 打开编织台：左边是 3 个咒式栏，右边是符文盘。选中咒式栏 → 选符文 → J 放入，中间的魔法阵会按新的组合一笔一笔重新画出来。光标停在符文上时会预览组合，K 清空咒式栏
- 魔法阵的样子由组合决定：元素决定颜色和外圈的符文字，形态决定内圈图形（弹是三角，环是同心环，柱是八芒星，抛是五芒星）
- 编织不花材料，可以随便试

| | 弹 | 环 | 柱 | 抛 |
|---|---|---|---|---|
| **星** | 星星弹 | 星光环：把周围的东西推开 | 星芒柱：把敌人挑上天 | 星屑炸弹：落地炸开 |
| **火** | 火球术 | 烈焰之环：点燃身边所有敌人 | 火焰喷泉：持续灼烧的火柱 | 燃烧瓶：落地留下一片火海 |
| **冰** | 冰锥术：掠过水面冻出冰路 | 霜华新星：冻住身边一切，脚下水面结冰 | 冰晶石柱：能站上去，湖面上也行（最多同时 2 根） | 冰霜弹：冻住一片；落在湖上冻出浮冰 |
| **雷** | 落雷术 | 静电爆发：电弧打向身边所有敌人 | 避雷针：自动电击靠近的敌人 | 引雷种：落地召来落雷 |
| **花** | 花瓣弹：缠住敌人，和小动物交朋友 | 花开之环：恢复 1 颗心，让砍倒的树马上长回来 | 藤蔓阶梯：三片叶子可以一级级跳上去 | 弹跳蘑菇：踩上去高高弹起（按住跳跃更高）；落在湖上长出荷叶 |

火系的任何形态都能烧荆棘墙，雷系的任何形态都能唤醒远古魔法门。

**花之魔法**不会伤害小动物：兔子被花瓣打中会冒出爱心，变成朋友，之后会一蹦一蹦跟着你；生气的野猪会马上消气。对史莱姆则是用藤蔓把它缠住一会儿（缠住时不能动，也碰不伤你）。花瓣会穿过树木，顺便给它们浇水：绿树会结出苹果，树桩会重新长出来。交到的朋友数量会存档。

石碑：「环」在裂开的岩墙后面，「抛」在丘陵中段一朵云上（要飘上去才能读），「柱」在低语森林里。越往深处走，石碑越残破……

## 冒险路线

```
魔法丘陵 ─[裂开的岩墙]─ 魔法丘陵 ─[荆棘墙]─ 低语森林 ─ 镜之湖 ─ 远古遗迹 ─[远古魔法门]─ 史莱姆王座
             蓄力星光柱    │         火之符文                  冰之符文            雷之符文        Boss
                        兔子洞（两个洞口，地下连通）
```

- **裂开的岩墙**：蓄力星光柱打碎（2 级一下，1 级要两下），里面有石头和水晶
- **兔子洞**：丘陵上的洞口，站在洞口按 ↑ 钻进去。洞里有软土墙（任何攻击魔法都能轰开）、单向木板、小水坑和兔子，从另一头的隧道爬上去，会从第二个洞口出来
- **荆棘墙**：只怕火，任何火系魔法打中后都会烧起来化成灰
- **镜之湖**：一串小岛和水塘交替排开。湖上雾太重不能飘浮：窄的水塘跳过去，宽的用冰锥掠过水面冻出冰路（18 秒后融化），或者用冰柱、花之「抛」长出的荷叶当踏脚石；水塘中间有石墩可以歇脚。掉进水里扣半颗心，回到最后站过的岸边。敌人和动物掉进水里就回不来了
- **远古魔法门**：雷电打中门上的水晶，门会沉进地里（落雷、静电爆发、避雷针都可以）
- **史莱姆王座**：进去后入口被封住，史莱姆大王从天而降。它会连跳、高高跳起砸地放出冲击波（跳过去！）、召唤小史莱姆；血量一半以下会生气，变得更快。冰冻后再打能碎冰加伤害
- 每一关旁边都有**路牌**，走近会显示提示；路上的**石灯笼**是存档点，最后碰到的灯笼就是复活点（花园门口的灯笼可以旅行过去）
- 进入新区域时会显示区域名字
- 生命值以半颗心为单位：被敌人撞到扣 1 颗心，掉进水里或坑里扣半颗心

## 剧情和台词

台词都写在 **`src/story/script.txt`** 里（写法见文件开头）。游戏里按 **F3** 打开剧情编辑器（或 F2 地图编辑器里的「对话 · 任务 · 时间」）：对话页就是这个文件，像写剧本一样直接打字，停手后自动保存，游戏里立刻生效。任务页和时间页编辑 `src/story/content.json`（Ctrl+S 保存）。也可以直接用任何文本编辑器改 script.txt，保存后游戏里不用刷新就会更新。

- **人物**：在地图编辑器里放「人物」，选是谁（外观来自 people.json），从列表选对话。走到旁边按 ↑ 说话；选中人物后可直接打开关联对话
- **剧情触发区**：看不见的区域，第一次走进去时自动开始一段对话（比如开场、Boss 前的自言自语）
- **出现条件**：人物和触发区可填 `boss`、`!fire`、`木头>=3`、`day>=2`、`period=evening` 等；也可在地图属性里选限定时段
- **任务**：`quest` 动作接取任务，任务页设置阶段、目标和提示；达到勾选自动推进的阶段条件时进入下一阶段，最后一阶段完成任务。`stage 任务ID 阶段ID` 可手动跳阶段，`done 任务ID` 可由交付对话完成任务。`{木头}` 在提示里实时显示背包数量
- **时间**：时段依次为早晨、午后、傍晚、夜晚。时间不会按现实秒数流逝；睡觉进入下一天早晨，`period evening` 可指定时段，`nextperiod` 推进一个时段（夜晚时需睡觉才能进入新的一天）。时间事件同一天只触发一次，触发记录和任务阶段会存档
- **教学**：`!wait 魔法 按 J 挥动法杖` 会先收起对话框，等玩家真的按下 J 再接着说
- **演出**：`!pause 1.5` 停顿；`!act 苹果婆婆 跳`（转身 / 跳 / 走 30 / 退场 / 出场）；`!camera 苹果婆婆` 镜头看向她，`!camera 阿梨梨` 回来；`!shake 2` 震屏；`!sfx 叮` 音效。对话会等这些做完再继续
- **结束**：`* 算了 -> 结束` 选了就结束对话
- **法杖**：新游戏一开始没有法杖，不能用魔法；脚本里 `!wand` 让阿梨梨从帽子里拿出法杖
- **木桥**：编辑器里的「木桥」物件，填一个「修好的条件」标记（比如 `bridge`）。没有这个标记时是断桥，脚本里 `!flag bridge` 的那一刻木板会一块块落下来修好。桥下的河或者坑要你自己画
- **人物外观**在 `src/story/people.json`：复制一段改颜色就是一个新人物。发型 `long` / `bun` / `short`，帽子 `witch` / `tall` / `scarf` / `straw` / `helmet` / `none`，`tall` 是比阿梨梨高几个像素
- 剧情编辑器保存后直接更新当前游戏；手改 content.json（任务、时间）需要刷新页面
- 开发时按 F4 可以清空存档，从开场重新看一遍

## 地图编辑器（F2）

用 `start.bat` 或 `npm run dev` 启动后，游戏里按 **F2** 打开编辑器，再按 F2 就从视角中间开始试玩。所有地图都存在 `src/maps/*.json`，编辑器保存（Ctrl+S）会直接写回这些文件。

- **地图**分两种：「大地图」是横向的丘陵漫步地图，按区域分成几块，走到边缘就无缝切到下一块：`hills`（小屋所在）→ `hills_east` → `forest` → `lake` → `ruins`；「房间」是从门进去的地方（兔子洞之类）。想再加一块大地图：新建房间后在「地图设置」里把类型改成大地图、背景改成天空，两边各放一个「隐形通道」门互相连起来。左上角下拉框切换地图，「新建房间」新建一个；如果当时选中了一个门，新房间的入口会自动和它双向连通
- **画地形（B）**：地形是 8 像素一格。选材质（1-7：草地、泥土、岩石、软土、水、单向平台、挖空）和形状（Q / E 切换：实心、半块、45° 坡、缓坡、天花板斜面），左键画、右键擦，Shift+拖动画矩形，Alt+点击吸取，X 切换 3×3 大笔刷
- **起伏线（H）**：大地图的地面可以用一条起伏线来画，点和点之间是圆滑的丘陵曲线，还能打开「随机小起伏」让地面有手绘感（丘陵、森林、遗迹现在都是这样）。左键拖动点、点空白处加点、右键或 Delete 删点；C 把选中的点变成**断崖**（地面在它前面保持高度，到这里直直落下或升起），F 让从这个点到下一个点保持平整、不加小起伏。站在地上的东西会跟着地面一起移动。线下面全是草地，瓦片画在它上面；要在线下挖洞或凹进去，用材质 7「挖空」
- **洞顶线（H 里按 T 切换）**：和地面线一样画，但线**上面**全是泥土，两条线中间就是洞，适合画地下洞穴的大轮廓。房间地图里，地面线下面是泥土而不是草地
- **地表深度（地图设置）**：填「最上面一行在地表下多深（px）」，泥土就按离地表的深度分层上色（浅沙土 → 橙土 → 深土 → 偏冷的紫褐土），越深石头越多越大，浅处的洞顶会垂下树根。挖在丘陵下面的洞把深度填对，颜色就能和上面的地面接上
- **光柱（物件）**：从地面的洞口斜斜照进洞里的光，带飘浮的尘粒；光落到的洞底会长苔藓。可以调顶部宽度和长度
- **放物件（O）**：树、石头、水晶、史莱姆 / 兔子 / 野猪（打倒后过一会儿会在原处重生）、云朵平台、路牌、存档灯笼、门、元素门、符文石碑、区域名、石柱等。左键放置（会自动落到地面，按住 Alt 放在原处），右键删除
- **选择（V）**：点物件选中，拖动移动，左边面板里改属性（路牌文字、门通往哪里、石碑的符文……），Delete 删除
- **门**：「兔子洞口 / 隧道口 / 山洞口」要站在门口按 ↑；「隐形通道」走进去就切换，适合房间边缘的隧道。门的「通往」选另一个门，如果那个门还没通到哪里，会自动连回来
- **掉进洞里**：在洞底放一个「掉落口」（看不见的区域，宽高可调），「掉到哪里」选另一张地图里的「落下点」。角色掉进掉落口不会扣血，会从落下点的位置在半空中出现、继续往下掉。落下点要放在空中（放置时按住 Alt 就不会贴到地面）；掉落是单向的，不会自动连回去
- 「地图设置」里可以改名字、类型、背景，调整地图大小（可以加在右下，也可以加在左上）
- 视角：WASD / 方向键（Shift 更快），滚轮缩放，中键或空格+拖动平移。Ctrl+Z 撤销，Ctrl+Y 重做，G 开关网格

## 已实现

- **打击感**：顿帧（hitstop）、受击闪白、屏幕震动、挤压拉伸、击退、碎屑粒子（会在地面弹跳）、伤害数字、冲击闪光和冲击波环
- **魔法**：星星弹（施法时手前会出现小魔法阵）；蓄力魔法阵分两级，魔法阵会一笔一笔画出来，包括旋转符文环和六芒星
- **资源**：树（绿树、粉色花树，部分结苹果）、石头（被打时会出现裂纹）、魔法水晶。被打时会晃动，打坏后会重新长出来
- **生物**：史莱姆（会追着玩家跳，大史莱姆更耐打）；兔子（会逃跑）；野猪（平时是中立的，被打后会生气，先刨地再冲锋，撞墙会眩晕）
- **掉落物**：弹出落地、弹跳，靠近时会被吸过来；连续拾取时音高会逐渐升高；苹果和肉能回复生命
- **地图**：瓦片地形（8 像素一格，有坡道、半块、天花板和洞穴），丘陵大地图按区域分成 5 块（边缘无缝衔接，一共约 5600 像素宽），加上可以进出的房间；云朵平台、单向木板、能被魔法打碎的软土、会结冰的水。丘陵背景有 4 层视差，地洞有自己的背景
- **魔法星盘（技能树）**：按 E 打开。中央是魔导书，六条分支向外展开：星辰、火焰、寒冰、雷电、身体、丰收，共 20 颗星
  - 点亮一颗星后，它连出去的星才会出现；再远一层的只显示成“？”
  - 升级时材料会从顶部材料栏一个个飞进星星里（每落下一个音调升高一点），全部到齐后星星炸开、连线长出、新的星星弹出来；升满级会盖上金色的 MAX 印章；点亮新的元素符文有彩虹字和额外的烟花
  - 方向键 / WASD 在星星间移动（镜头会跟着滑过去），J / 空格 / 点击 升级，Q 或鼠标滚轮 缩放，鼠标拖动可以平移
  - 右侧说明卡片：彩色关键词、当前效果 → 下一级效果、需要的材料（够的变绿）；材料不够时卡片会抖一下并闪红
  - 旧存档会自动转换：已学会的魔法会变成对应的元素符文，并以「弹」的形态放进咒式栏；生命之心、云朵之羽都会保留
- **元素反应**：冰冻的敌人被火、雷、星星弹或蓄力魔法打中会“碎冰”，额外 +2 伤害
- **存档**：材料、符文、咒式栏、升级、打开的门、存档点、是否打败 Boss 都会自动保存到浏览器（每 15 秒、合成后、关闭页面时各存一次），魔法星盘右下角可以重置存档
- **音效**：全部用 WebAudio 实时合成

## 手感调整入口

- 跑速和跳跃高度：`player.ts` 顶部的 `RUN_SPEED`、`JUMP_V`、`FLAP_V`
- 蓄力时间：`player.ts` 顶部的 `CHARGE_L1`、`CHARGE_L2`
- 顿帧长度：搜索 `hitstop(` 后面的数字（单位是帧，1 帧 = 1/60 秒）
- 震屏强度：搜索 `shake(`
- 敌人数量和位置：用编辑器放；重生时间是 `level.ts` 里的 `RESPAWN_TIME`
- 能自动走上去的台阶高度：`entity.ts` 里的 `WALL_STEP`（现在是 6 像素，所以一整格 8 像素的台阶要跳）

## 接下来的目标

整体方向：小型银河城 + 符文编织 + 温馨养成。战斗为辅，重点放在探索、交朋友和把世界变好。不直接讲故事，只用环境暗示。

1. **污染与净化**：远古遗迹和史莱姆王座一带变成灰紫色的污染区（草枯了、树变灰、小动物缩成一团）。先打碎地上的污染结晶，再用花之魔法净化，那一片就会重新变回彩色、开花，小动物醒来。每个区域有净化进度，全部完成后，Boss 洞穴里那个画错的魔法阵会慢慢愈合
2. **小屋扩建**：花材料扩大花园，住下更多朋友；添加池塘和家具；用「抛」把种子扔进花圃，睡几天长出果树和花丛。净化后的史莱姆和新的小动物（小鸟等）也能搬进来
3. **背景音乐**：每个区域一段程序生成的旋律，小屋里有专属的温馨曲子
4. **元素蓄力**：按住 K 放出的大招跟随当前元素变化（火是陨石，冰是冰川，雷是雷暴，花是巨树）
5. **新手引导与数值平衡**：在第一块石碑前简单教玩家按 R 编织；根据试玩感受统一调整各种魔法的伤害、冷却和材料价格
6. **地图网状化**：（编辑器和房间系统已经有了）用编辑器继续加地下洞穴（要用火照明）、树顶（要用藤蔓爬上去），在旧区域埋下学会新符文后才能拿到的秘密
7. **区域专属敌人与更多 Boss**：森林的蘑菇怪、湖里的水母、遗迹的石像守卫


### 对话编辑工作流

按 F3 打开剧情编辑器的对话页。顶上的「节点 / 文本」切换两种写法，改的是同一个 `script.txt`，随时可以切换。

**节点模式**（默认）

- **左边**：按人物整理画布。同一人物出现在多个地图时，点击人物展开地图子项，每张地图有独立的对话画布；顶栏显示「人物 / 地图」。首次打开节点模式时，原来共用的对话和自言自语会复制成独立分支，并自动更新各地图人物的关联。未被地图使用的旧草稿保留在「未分配对话」。只有一张地图的人物直接进入画布。不属于某个人的剧情是「剧情事件」（`【事件 · 开场】`）。📍 表示已经放进地图。普通画布可双击改名、右键删除；地图子项的名字跟随地图名；「＋ 新人物」可以直接选 people.json 里的人。
- **中间画布**：从左往右连线。
  - 右键空白处加节点；从节点右边的圆点拖出连线，拖到别的节点上就连上，拖到空白处会弹出菜单、直接接一个新节点；点一下圆点再点目标节点也行
  - 双击连线断开；拖空白处平移，滚轮缩放；Delete 删除，Ctrl+D 复制，Ctrl+Z / Ctrl+Y 撤销重做，F 适合内容
  - 「一键整理」自动排列，并把首尾相连的对话节点合成一个
- **右边**：上面是预览舞台（选中哪句演哪句，「▶ 从这里演」时正在演的节点会发绿光），下面是选中节点的属性。对话节点里回车加下一句，说话人自动换成对方。
- **节点种类**：开始、对话、选项、判断（是/否）、跳转（去别的画布）、结束；标记、物品、学会（符文/法杖）、任务、演出（大字/回血/结束画面/时段）；停顿、人物动作、镜头（看向某人/震屏）、音效、等玩家操作。
- 节点的位置和画布的地图归属存在 `src/story/layout.json`。地图分支使用稳定的地图编号，地图改名不会新建一份对话。第一次用节点改剧情时，script.txt 会被整理成统一的格式（段落顺序、空行），剧情内容不变。拆分可撤销、重做，人物的对话关联会一起恢复。

**文本模式**：像写剧本一样打字。

- **左边目录**：按 `【章节】` 分组列出所有段落，标出它在哪张地图被谁用（📍人物、▦触发区、💭自言自语、⏰时间事件），没人用的标「未使用」，有问题的标红。顶上的搜索框会搜台词内容。「＋ 新段落」在当前段落后面加一段。
- **中间剧本**：直接打字。说话人按剧情里的颜色上色，出错的行画红波浪线，底部状态栏说明问题。
  - 回车换行后会提示下一个说话人（通常是刚才那句的对方），按 **Tab** 选用，直接打字则忽略
  - 打 `名字(` 提示表情，打 `->` 提示段落，打 `?` 提示标记/物品/任务条件，打 `!` 提示命令和参数
  - 选项行按回车自动接下一个 `* `，空选项再回车结束
  - **Ctrl+点击** `-> 段落` 跳过去；**Ctrl+/** 注释/取消注释；Ctrl+Z 撤销
- **右边**：同样的预览舞台，下面是自动画出的对话流程。

两种模式都是停手 0.7 秒自动保存；如果同时在别处改了文件，会提示选哪个版本。

地图分支回归检查：运行 `npm run test:map-dialogue`。需要手动检查界面时，开发服务中的 `/scripts/map-canvases-preview.html` 提供隔离样例；该页面的保存只进入浏览器会话存储，不会写入项目剧情和地图。

地图上的人物不再手动选择普通对话段落。点击「编辑此地图的对话」会自动关联到人物在当前地图的画布，只有一张地图或尚无台词的人物也适用。在画布中选中「开始」节点，点击「设为此地图的对话入口」可更换交谈入口；同一地图中的同名人物一起使用该入口，其他地图不受影响，支持撤销和重做。原有台词会保留。自言自语的段落、范围、间隔，以及人物的出现规则、初始朝向仍在地图面板设置；剧情触发区仍可手动选择段落。
