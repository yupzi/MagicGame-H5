# ============================================================
#  阿梨梨去上学 · 台词脚本（草稿，随便改）
# ============================================================
#
#  写法：
#    【人物名】              一个人物的所有对话放在一起（编辑器里是一张画布）
#    【事件 · 名字】         不属于某个人的剧情（开场、触发区、时间事件）
#    == 段落名 == 标题       一段对话的开头。地图上的人物/触发区用段落名来找台词；
#                           后面的标题可以不写，只给自己看
#    名字: 台词             有人说话（冒号用中文 ： 或英文 : 都行）
#    名字(表情): 台词       带表情：普通 开心 惊讶 汗 困 生气 得意
#    旁白: 文字             没有头像的叙述
#    名字: （心里话）        整句用（）括起来 = 心里想的，显示成虚线气泡
#                           台词会变成气泡浮在说话人头顶；旁白显示在屏幕上方；
#                           说话人不在画面里时，改用屏幕下方的对话框
#    （不写名字的一行）      接着上一个人说，新开一页
#    * 选项 -> 段落名       选项，连着写几行就是几个选项；不写 -> 就接着往下
#    -> 段落名              跳到别的段落
#    ?条件 -> 段落名        条件成立就跳过去。条件可以是：
#                             标记          有这个标记
#                             !标记         没有这个标记
#                             木头>=3       背包里的东西够不够（也能用 > < <= =）
#                           可以用空格连着写几个，全部成立才跳：?wand 木头>=3 -> 段落
#    # 开头的是注释
#
#  命令（! 开头）：
#    !flag 标记 / !unflag 标记   记住 / 忘掉一件事（会存档）
#    !item 木头 3                得到东西
#    !take 木头 3                交出东西
#                                东西：木头 石头 水晶 凝胶 毛皮 苹果 肉
#    !wand                       从帽子里拿出法杖（之后才能用魔法；会记下标记 wand）
#    !learn fire                 学会元素符文：fire 火 / ice 冰 / thunder 雷 / flower 花
#    !form ring                  学会形态符文：ring 环 / pillar 柱 / lob 抛
#    !wait 魔法 按 J 挥动法杖      对话框先收起来，等玩家做了这个动作再接着说。
#                                可以等：魔法 蓄力 跳 切换 走 左 右 上 下；后面是提示文字
#    !quest 任务名 文字           右上角出现一条任务，文字里的 {木头} 会显示成背包里的数量
#    !done 任务名                 完成任务（任务条消失）
#    !heal                       回满血
#    !banner 文字                屏幕中间出现大字
#    !ending                     显示结束画面
#    !end                        对话到此结束（也可以写 -> 结束，比如 * 算了 -> 结束）
#
#  演出（对话会等它们做完）：
#    !pause 1.5                  停顿 1.5 秒，气泡先收起来
#    !act 苹果婆婆 跳             人物动作：转身 / 跳 / 走 30（负数往左）/ 退场 / 出场
#    !camera 苹果婆婆             镜头看向某人；!camera 阿梨梨 就回来（对话结束也会回来）
#    !shake 2                    震屏，强度 1~3
#    !sfx 叮                     音效：叮 跳 噗 魔法 得到 回血 解锁 轰隆 水花 吼叫 跺地 胜利 翻书 不行 存档 弹跳 交朋友 爆炸 闪电 开花 嘶 心跳
#
#  会说话的人（名字要写得一模一样才有头像），外观在 src/story/people.json 里改：
#    阿梨梨  妈妈  建筑工  苹果婆婆  阿鲈  闪闪学姐  老师
#
#  自动记下的标记：学会元素时记 fire / ice / thunder / flower，
#  打败史莱姆大王记 boss，拿到法杖记 wand。
#  「木桥」物件没有它的标记时是断桥，一旦 !flag 了这个标记就会当场修好。
#  自言自语（玩家不用停下来，气泡自己一句句冒出来）：
#    在编辑器里给「人物」填「自言自语」，玩家走近时就会说；
#    或者把「剧情触发区」的方式改成「自言自语」，走进去时说（说话人按台词里的名字找）。
#    自言自语里的选项、!wait 会让它直接结束；旁白和不在场的人说的话会被跳过。
#  改完保存就生效，不用刷新页面。
# ============================================================
